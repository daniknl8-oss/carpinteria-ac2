☁️ Sincronización en la Nube (Firebase)
Introduce los datos de tu proyecto Firebase para sincronizar entre el móvil y el ordenador. Los datos quedan guardados en este navegador para no tener que introducirlos cada vez.
👉 Abrir Firebase Console (gratuito)
📋 Pasos (5 minutos, gratis):
1· Ve a console.firebase.google.com → "Crear proyecto" → nombre ej: carpinteria-ac
2· Panel del proyecto → icono </> Web → registra la app → copia los datos de firebaseConfig
3· Ve a Firestore Database → "Crear base de datos" → Modo prueba → Europa
4· Pega los datos aquí y pulsa "Conectar" → ¡sincronización activa en todos tus dispositivos!
